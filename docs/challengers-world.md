# 챌린저스 종료와 스카니아 통합

2026-09-15: 캐릭터 이전 완료에 따라 앱을 스카니아 단일 장부로 전환.

## 데이터 보존

- DB와 로컬 저장소의 원본 서버, 날짜, 금액, ID를 일괄 변경하거나 삭제하지 않는다.
- 앱은 기존 챌린저스 기록과 현금 판매 기록을 스카니아 기록으로 해석한다. 새 기록은 스카니아로 저장한다.
- 잔액, 채무, 주간 수익, 기록 목록, 판매 가능 금액 모두 통합 장부를 사용한다.
- 과거 서버 이동은 원래 출발/도착 서버로 기록 화면에 남는다. 계산에서는 양쪽을 스카니아로 합쳐 `받은 금액 - 보낸 금액`만 반영하므로 기존 수수료가 보존된다. 통합 자체에는 수수료가 없다.
- 내보내기는 원본 서버를 가진 메이플 기록을 보존한다. 기존 내보내기 기능은 현금/이동 기록 전체 백업이 아니다.
- 기존 기록을 편집해 저장하면 그 기록의 서버는 현재 통합 서버인 스카니아로 저장된다.

## 다음 시즌 재개

`src/lib/mapleServers.ts`의 `CHALLENGERS_ENABLED`를 `true`로 변경한다.
`CHALLENGERS_MERGED_BEFORE`를 다음 시즌 시작 시각(시간대 포함)으로 갱신한다.
이 시각 **이전에 생성된** 챌린저스 기록은 계속 스카니아 소속이다. 이후 새 챌린저스 기록만 새 시즌에 쌓인다. 기록 날짜를 과거로 입력해도 생성 시각을 기준으로 시즌을 구분한다.

서버 선택, 서버 이동 입력, 두 서버 대시보드가 다시 나타난다. 기본 입력 서버는 스카니아로 유지된다.

재개 전 `node scripts/test-world-merge.mjs` 및 빌드를 실행한다. 이전 시즌 잔액이 다시 챌린저스로 분리되지 않는지, 신규 양방향 이동과 수수료가 맞는지 확인한다.
